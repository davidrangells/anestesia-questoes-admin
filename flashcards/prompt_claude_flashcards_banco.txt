Você é o Claude Code atuando no projeto Anestesia Questões.

Objetivo:
Implementar suporte a um novo banco de dados de Flashcards no Firestore usando a planilha de importação "anestesia_flashcards_import_2026-06-26.xlsx".

Contexto:
Antes, os flashcards estavam sendo exibidos diretamente a partir do banco de questões. Isso deixava a experiência confusa, porque a frente do card mostrava um enunciado de questão e o verso mostrava apenas a alternativa correta, às vezes como "Letra C", sem as alternativas na frente. A nova abordagem separa conceitualmente:

- Questões = treino de prova, com enunciado, alternativas e comentário completo.
- Flashcards = revisão rápida, curta e objetiva, com frente, verso e explicação resumida.

Como a planilha foi criada:
A planilha original exportada do Firebase tinha 2.300 questões. Para cada questão, foi gerado 1 flashcard inicial em modo rascunho/revisão, mantendo vínculo com a questão original.

A lógica usada foi:
1. sourceQuestionId recebeu o docId original da questão.
2. frontText recebeu o enunciado limpo de HTML e encurtado quando necessário.
3. backText recebeu o texto da alternativa correta.
4. shortExplanation recebeu um resumo inicial da explicação original.
5. themeId foi gerado a partir do tema principal em formato slug.
6. deckIds foi preenchido com decks sugeridos, separados por ponto e vírgula.
7. tags foi preenchido com tags sugeridas, separadas por ponto e vírgula.
8. status ficou como "pending_review".
9. isActive ficou como false para evitar publicação automática.
10. needsReview ficou como true para obrigar revisão humana antes de publicar.

Importante:
A planilha é uma base inicial de importação e revisão. Não publicar automaticamente os cards para os alunos. O admin deve revisar/editar/aprovar antes de tornar isActive=true e status=published.

Estrutura das abas:
1. Flashcards_Import
   Contém os flashcards a importar.
2. Decks_Import
   Contém decks sugeridos para organização dos flashcards.
3. Estrutura_Campos
   Documenta o significado de cada campo.
4. Validacoes
   Lista status, difficulty e sourceType permitidos.

Regras de importação da planilha:
- Ler a aba Flashcards_Import.
- Para cada linha:
  - Usar flashcardId como ID do documento, se possível.
  - Converter deckIds de string separada por ";" para array.
  - Converter tags de string separada por ";" para array.
  - Converter isActive e needsReview para boolean.
  - Não publicar automaticamente cards com status pending_review.
  - Ignorar ou registrar erro se frontText/backText estiverem vazios.
- Ler a aba Decks_Import.
  - Usar deckId como ID do documento.
  - Importar decks inicialmente como pending_review e isActive=false.

No app do aluno:

- Na frente do card, mostrar frontText.
- No verso, mostrar backText e shortExplanation.

Lógica inicial de repetição espaçada:
- Não sabia: nextReviewAt = amanhã, box = 1, timesWrong +1.
- Quase: nextReviewAt = hoje + 3 dias, box = max(box, 2), timesAlmost +1.
- Sabia: nextReviewAt = hoje + 7 dias, box = box + 1, timesCorrect +1.
- Se box avançar bastante, pode marcar como mastered depois de critérios definidos.
